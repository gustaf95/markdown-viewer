## 긴 표 (가로 스크롤 확인)

| 순번 | 기능 식별자 | 기능 이름 | 상세 설명 | 우선순위 | 담당 모듈 | 상태 | 비고 |

| 1 | F-001 | 파일 열기 대화상자 | 사용자가 파일 열기 대화상자를 통해 Markdown 파일을 선택할 수 있어야 한다 | 1순위 | main | 완료 | Ctrl+O |
| 2 | F-101 | 제목 렌더링 | 제목 계층 구조를 정확하게 렌더링해야 한다 | 1순위 | renderer | 완료 | h1~h6 |
| 3 | F-301 | 인라인 수식 | 달러 기호로 감싼 인라인 수식을 지원해야 한다 | 2순위 | renderer | 완료 | KaTeX |
